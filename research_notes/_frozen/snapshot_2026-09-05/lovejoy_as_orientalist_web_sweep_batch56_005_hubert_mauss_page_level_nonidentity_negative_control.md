# Batch 56 — 005 × Hubert–Mauss 1899: page-level non-identity as a negative control on direct transmission

Date: 2026-08-18
Status: synced
Scope: test whether the shared source constellation identified in Batch 55 can be upgraded from `shared field` to `shared packet / direct textual pathway` by comparing page-level references where recoverable.

## Core result

The first page-level check does **not** support an upgrade to direct packet identity. In the clearest cases, Hubert–Mauss and Lovejoy cite the same books but apparently use **different loci** or Lovejoy’s locus remains too uncertain to match.

That negative result is valuable. It makes the historical model more discriminating:

> **same source constellation + different page selections = common documentary field is stronger than direct copying from one fixed packet.**

This fits the broader project argument unusually well: Marillier’s research environment may have organized a repertoire of books, cases and classificatory problems without dictating identical extracts or identical conclusions.

## 1. Kingsley: same book and problem neighborhood, apparently different page

### Hubert–Mauss

In the blood/idol-anointing footnote they cite:

- Miss Kingsley, *Travels in West Africa*, **p.454**;
- immediately alongside Marillier, *Revue de l’histoire des religions* (1898), I, p.222.

The source is therefore very precise.

### Lovejoy 005

Lovejoy uses Kingsley in PDF pp.89–90 for West-African fetish/amulet beliefs, blood-protected houses, and the independent magical potency of blood. The corrected transcription of p.90 says the visible Kingsley page number appears to be **c.525**, but is not fully secure.

At present, then:

`Hubert–Mauss: Kingsley p.454`  
`Lovejoy: Kingsley c.p.525 [?]`

This is not an exact extract match. The overlap remains strong at the level of **book + region + blood/fetish problem**, but weakens a claim that Lovejoy simply received the same excerpt or followed Hubert–Mauss’s footnote trail.

A visual second-pass of 005 p.90 should be done before treating `525` as final.

## 2. Callaway: Hubert–Mauss give pp.59/92; Lovejoy appears to use other locations

### Hubert–Mauss

Their footnotes explicitly cite Callaway, *The Religious System of the Amazulu*:

- p.59 n.14 in one sacrificial comparison;
- p.59 and cf. p.92 in another later note.

### Lovejoy 005

Lovejoy’s p.63 bibliography names Callaway’s *Religious System of the Amazulu*. Several later African/Zulu notes draw on Callaway. The raw/canonical trace around PDF p.74 appears to contain a reference `Callaway 143` in a discussion of offerings to the dead, contract/advantage, and sacrifice; p.77 also contains a Callaway cluster, but its exact page reference is not secure in the first-pass transcription.

Therefore the current evidence is:

`Hubert–Mauss: 59 n.14 / 92`  
`Lovejoy: apparently 143 and other uncertain loci`.

Again, same book does not presently equal same extracted page.

This is exactly the kind of negative control needed before calling the overlap a `shared source packet`.

## 3. Trumbull: exact titles coincide, but page identity is not yet demonstrated

Lovejoy’s p.62 bibliography contains both books, and pp.78, 84–86 work through the same broad blood/foundation/union problem. However, the corrected transcription marks Lovejoy’s specific Trumbull page numbers as uncertain.

Thus Trumbull is currently the **strongest candidate** for a shared page-level route, but it is not yet closed.

A direct visual read of 005 pp.78, 84–86 against Trumbull’s tables/pages would be the next high-value collation.

## 4. Why non-identity matters methodologically

A historiography built only from shared titles could easily overread documentary proximity as influence. The page-level test creates a hierarchy:

1. **same disciplinary topic** — weak;
2. **same book** — stronger but often ambient;
3. **same book + same problem node** — strong shared-field evidence;
4. **same exact pages / unusual cases / sequence** — possible shared packet or pathway;
5. **same wording / copied errors / citation sequence** — much stronger direct textual dependence.

The present Hubert–Mauss/Lovejoy evidence is mostly level 3, with Trumbull potentially approaching level 4. It is not yet level 5.

This hierarchy mirrors the influence-warrant rule reconstructed from 004 itself: resemblance is not enough; transmission claims require discriminating conjunctions.

---

## 5. The negative result actually improves the Marillier-workshop model

If Lovejoy and Hubert–Mauss used exactly the same page extracts in exactly the same order, one might suspect direct borrowing from a fixed bibliography or packet. The preliminary non-identity suggests a more generative environment:

- shared canonical and semi-canonical works circulate;
- Marillier publishes and teaches problem-specific critiques;
- students/researchers select different cases from overlapping books;
- the same source field is re-divided rather than copied wholesale.

That is consistent with Söderblom’s explicit statement that he used Marillier’s problem/material while making `different divisions`, and with Mauss’s acknowledgment of receiving Marillier’s bibliography and course notes.

For Lovejoy, direct receipt of the same documents remains unproved; but the source pattern now looks more like **bibliographic infrastructure** than a single transferable script.

## 6. Paper-level formulation

> **The overlap between Lovejoy’s notebook and Hubert and Mauss’s 1899 essay should not be mistaken for page-for-page dependence. A preliminary citation audit points in the opposite direction: the same books recur at corresponding analytical nodes, but the recoverable page references are not identical. Kingsley appears at p.454 for Hubert and Mauss and around p.525 in Lovejoy; Callaway’s pp.59/92 in the essay do not match Lovejoy’s apparent p.143 citation. What circulated, therefore, may have been less a fixed packet of quotations than a structured bibliography and problem field. This is precisely the kind of documentary environment in which reclassification, rather than replication, becomes historically visible.**

Compact formulation:

> **bibliographic convergence without extract identity.**

---

## Evidence cautions

1. Lovejoy’s Kingsley `c.525` and Callaway `143` readings require visual second-pass confirmation before publication.
2. Absence of an exact page match in the currently readable references does not prove that no shared packet existed elsewhere.
3. Hubert–Mauss’s citations are taken from the 1909 reprint text of the 1899 essay; original 1899 pagination should be used in final scholarly citation.
4. Do not downgrade the shared-field evidence simply because pages differ: source + problem-node convergence remains historically meaningful.
5. Do not upgrade to direct textual dependence unless exact unusual examples, page sequences, copied wording, or documentary transfer evidence appears.
