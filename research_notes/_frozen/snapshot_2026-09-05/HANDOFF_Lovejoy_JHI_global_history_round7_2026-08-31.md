# VII. Governing method architecture

The project now distinguishes at least five non-reducible layers:

`ARGUMENT`
+
`CARRIER`
+
`CURRICULUM`
+
`NETWORK`
+
`CANON`.

Expanded shorthand:

> **METHOD CHANGE = ARGUMENT + CARRIER + CURRICULUM + NETWORK + CANON, with no term reducible to another.**

This sits alongside UNIT×RELATION:

`WHAT UNIT?`
-> `WHAT RELATION?`
-> `WHAT PROOF BURDEN?`
-> `WHAT CARRIER?`
-> `WHAT NETWORK / CURRICULUM MAKES IT RECURRENT?`
-> `WHAT LATER CANON MAKES IT PORTABLE?`.

Do not imply a single causal direction.
