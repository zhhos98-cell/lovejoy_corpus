## 1. Recovery rule

- Git history is the archive layer.
- Do **not** recreate deleted working files under an `archive/` directory merely for preservation.
- A batch/process file is removable only after its unique primary evidence, matrix or verdict has an explicit living home.
- Primary/corrected transcriptions, source matrices, registers and unique source microhistories are not deleted merely because they are old.
- Because another write stream may update `main`, deletion/update operations must use the current exact blob SHA.

## 7. Restart rule for further cleanup

When continuing:

1. inspect the actual content of a candidate file;
2. identify its unique proposition(s), source pages and data products;
3. locate a later living home for every unique item;
4. if no such home exists, retain the file or consolidate first;
5. delete only the superseded prose/process state, not the evidence merely because its batch number is old;
6. update this manifest and `CURRENT_STATE.md` only after a meaningful cleanup group is complete.
