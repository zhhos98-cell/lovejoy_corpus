# Lovejoy 1906 — confidence vocabulary and scale-promotion micro-audit

Date: 2026-08-28  
Status: **MICRO-AUDIT / CLAIM-LEVEL TARGET FOR NEXT DIRECT-TEXT PASS**

Primary target: Arthur O. Lovejoy, `The Fundamental Concept of the Primitive Philosophy`, *The Monist* 16 (1906).

## Purpose

Test a specific hypothesis generated by the mechanism-sensitive-warrant stress test:

> Lovejoy's local source/semantic claims may be more carefully calibrated than his final high-scale attribution of a `fundamental concept` to `primitive philosophy` as such.

This note establishes the coding protocol and currently supported claim architecture. It should be upgraded with exact page-level lexical hits from the full primary text in the next direct-text pass.

---

# I. Claim scales to code

### S1 — witness-level

Claims about what a particular observer/text says or records.

Examples:

- word X is used in context Y;
- observer Z reports practice P;
- translation `spirit` does/does not fit this passage.

### S2 — local semantic/mechanism

Claims about what a specific indigenous term/practice signifies or how efficacy is conceived in a local evidentiary cluster.

### S3 — regional comparative

Claims that several witnesses/peoples in one comparative packet instantiate a shared pattern such as transferable/localizable impersonal efficacy.

### S4 — cross-regional common core

Claims that geographically distinct evidence supports one minimal common conception.

### S5 — generalized primitive-philosophy target

Claims that the reconstructed conception is `fundamental` to primitive philosophy / savage thought generally.

The central test is whether modal/confidence language changes systematically from S1–S5.

---

# II. Confidence operators to extract

Direct-text pass should code every occurrence of:

- `probably`;
- `perhaps`;
- `apparently`;
- `seems` / `seems to`;
- `may` / `might`;
- `possible` / `possibly`;
- `likely`;
- `suggests`;
- `indicates`;
- `I think` / `I believe`;
- `must`;
- `clearly`;
- `plainly`;
- `certainly`;
- `undoubtedly`;
- `fundamental`;
- `essential`;
- `general` / `universal` where functioning as scale claims;
- explicit denials (`does not prove`, `cannot mean`, etc.).

Also code unmodalized categorical propositions at S4–S5, because absence of hedge is itself relevant.

---

# III. Preliminary pattern from existing direct audits

Existing repository controls establish three qualitatively different confidence practices.

## A. Source/gloss criticism — discriminating and local

Lovejoy often retains an observer's empirical report while rejecting the observer's personalistic interpretation or translation.

This implies proposition-level confidence differentiation rather than whole-source trust.

Expected coding:

- high confidence in reported rite/word;
- lower or negative confidence in ontology inferred by observer.

## B. Regional evidence — graded

Lovejoy uses some regional evidence only for minimal nonpersonal-power claims, while richer North-American materials support more detailed mechanism claims concerning localization, transfer and quasi-regular operation.

This is explicit evidence-strength scaling.

## C. Final macro-category — strong address

The title and governing thesis stabilize the target as **the fundamental concept of the primitive philosophy**.

Existing audits show Lovejoy does not merely offer `primitive energetics` as a historian's comparative convenience; he attributes the reconstructed abstraction to primitive/native thought itself.

This creates the scale-promotion question:

`graded local/regional evidence`
→ `strong cross-cultural actor-level category`.

---

# IV. What would confirm uneven scale-control

The hypothesis strengthens if direct lexical audit shows a pattern such as:

- S1/S2: frequent modifiers and explicit source differentiation;
- S3: regional qualifications;
- S4/S5: increasingly categorical language, especially `fundamental`, `general`, or unhedged actor attribution;
- without corresponding new evidence operators that justify the larger representativeness claim.

The problem would then be **promotion hardening**:

> uncertainty is handled carefully inside the evidence packet but diminishes as the analyst moves toward the synthetic comparative category.

---

# V. What would weaken the hypothesis

The hypothesis weakens if Lovejoy consistently:

- marks S4/S5 as tentative;
- explicitly defines the general category as a historian's minimal ideal type;
- repeatedly limits its representativeness;
- names counterexamples / domains to which it does not apply;
- distinguishes `common comparative core` from `concept possessed by all primitive actors`;
- gives a clear sampling or convergence argument for the scale upgrade.

If so, the 1906 macro-target would be more carefully controlled than current summaries suggest.

---

# VI. Why this micro-audit matters longitudinally

The result should be compared with:

### 1898

Local semantic certainty + corpus-level provisionality.

### 1923

Historian's broad category is decomposed before actor reconstruction.

### 1935

`Primitivism` becomes explicitly historian-owned terminology covering distinct tendencies.

### 1941/1944

Analyst-constructed relations/units are treated as hypotheses requiring return to historical evidence / examination of texts.

A strong 1906 `promotion hardening` result would support a developmental shift toward greater explicit ownership and provisionalization of analyst categories.

But it would not prove linear continuous improvement; later cases still contain over-attribution risks.

---

# VII. Relation to Orientalism / political stakes

Do not reduce the scale problem to a generic accusation of Orientalism.

The historically precise issue is:

- who owns the abstraction;
- what sample/evidence supports the cross-cultural identity;
- when a comparative type becomes an actor-level attribution;
- how confidence changes during that promotion.

This allows political/colonial context to be analyzed without substituting moral diagnosis for proof analysis.
