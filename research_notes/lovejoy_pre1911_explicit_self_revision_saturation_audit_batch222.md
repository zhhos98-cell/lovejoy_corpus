# ≤1910 explicit self-revision saturation audit — Batch222

Date: 2026-08-26
Status: **CLOSED AS SEARCH BRANCH / QUALIFIED SATURATION**
Scope: ordinary longitudinal endpoint ≤1910. Later material is used only as an external control, not as evidence inside the early sequence.

## 0. Question

After Batch218 established the 1909→1910 Kant correction, and Batch221 separated a 1910 formal-logic erratum from intellectual reclassification, is there another currently recoverable ≤1910 Lovejoy publication in which he explicitly revises the **scope/classification/predicate** of an earlier claim?

This is a saturation audit, not a proof of absolute nonexistence.

## 1. Search protocol

Anti-duplication and candidate search used:

- repository searches for `self-correction`, `error`, `correction`, `misconception`, `slip in writing`, `former paper`, and title-specific backward references;
- Daniel J. Wilson's annotated bibliography as a publication-level control for Lovejoy's early corpus;
- web-indexed full-text searches for Lovejoy + correction/retraction/mistake/backward-reference language in 1901–1910;
- exclusion of records already analyzed in Batches217–221.

A candidate counted only if it met more than the minimal condition `Lovejoy says something earlier was wrong`. To qualify as an intellectual self-reclassification it had to show at least one of:

1. new/closer source or context control;
2. redistribution of a broad predicate into narrower relation/domain predicates;
3. explicit narrowing of the licensed scope of an earlier historical/philosophical claim;
4. changed classification of the object under study.

## 2. Surviving ≤1910 cases

### A. 1909→1910 Kant — survives

Status: **DIRECT PRIMARY / INTELLECTUAL SELF-RECLASSIFICATION**.

Lovejoy explicitly returns to his own 1909 `Kant = evolutionist` formulation after closer investigation and decomposes it into non-equivalent evolutionary predicates by domain. This remains the clean positive control.

See Batches217–218.

### B. 1910 formal-logic correction — excluded from intellectual class

Status: **DIRECT AUTHORIAL CORRECTION / ERRATUM NEGATIVE CONTROL**.

`A Note from Professor A. O. Lovejoy`, *Journal of Philosophy, Psychology and Scientific Methods* 7.5 (1910), 133, corrects a local phrase in Rule IV of `The Treatment of "Opposition" in Formal Logic` (pp.101–105). Lovejoy calls it an erratum / writing slip escaping hasty proofreading. It repairs wording; it does not alter the classification or evidentiary scope of the analytic object.

See Batch221.

## 3. Post-cutoff control: 1914 Leuba feedback loop

The repository already contains a later case in which Lovejoy re-enters reception of his own 1906 `Primitive Philosophy` article. In 1914 he reviews Leuba's 1912 book; Wilson says Lovejoy attempts to correct Leuba's misconception of Lovejoy's 1906 position.

Status inside this audit:

> **EXISTS AS LATER CONTROL / EXCLUDED BY ORDINARY 1910 CUTOFF.**

The exact proposition corrected in 1914 remains primary-text HOLD in Batch84, so it should not be used to manufacture an early continuous self-revision chain.

This later case matters only negatively here: explicit authorial return/revision is not unique to Kant across Lovejoy's whole career, but the currently controlled early corpus does not supply another ≤1910 example of the same intellectual type.

## 4. Search verdict

> **Within the currently indexed repository, Wilson-controlled early bibliography, and recoverable web full text, the Kant 1909→1910 sequence is the only ≤1910 case presently surviving the stronger intellectual-self-reclassification threshold.**

This is a qualified corpus verdict, not an ontological claim that no unnoticed letter, lecture manuscript, short note, or inaccessible print item can exist.

Therefore the search branch should now be treated as saturated unless a new primary object appears. Repeating generic web searches for `Lovejoy + error/correction` is no longer a high-value move.

## 5. Consequence for Batch220

Do **not** formulate the early pattern as:

> Lovejoy repeatedly published explicit self-corrections before 1910.

The evidence supports the narrower formulation:

> **004/005 show repeated relation-specific reclassification in working notes; the 1909→1910 Kant sequence supplies one unusually explicit published authorial self-correction that makes the same pressure toward narrower predicates directly observable.**

That is methodologically stronger because it preserves the evidentiary asymmetry among notebook sequence, published self-revision, and later reception feedback.
