## 1. Core project problem

The project asks how Lovejoy's late-1890s work moved between textual criticism, comparative religion, philosophical reconstruction, and later published abstraction, with special attention to the evidential operations visible in notebooks 004/005 and the 1897–98 publication path.

The current working emphasis is source-critical and Lovejoy-local:

> **different relations require different warrants, and the research object can change between notebook work, announced communication, meeting record, article, and later synthesis.**

The key task is to reconstruct those changes from direct evidence without converting analytical resemblance across contemporaries into a historical argument.

→ `22–24 Apr 1897 Proceedings: On the meaning of the Buddhist technical terms [upādāna] and [upādāna-kkhandhā]` **(content-level recovery from indexed OCR; exact printed form still visual HOLD)**

→ `1898 JAOS: The Buddhistic technical terms upādāna and upādisesa`.

Current interpretation:

> The public-facing object changes at least twice: from a whole-text `Milinda-pañha` argument, to an `upādāna / upādāna-kkhandhā` term-pair problem, and then to the published `upādāna / upādisesa` pair. The second named term therefore changes between the late-April 1897 meeting state and the 1898 article. This is direct evidence of object revision across documentary states; it is not proof that one unchanged manuscript was repeatedly retitled.

The recovered 1897 term pair points directly toward notebook 004's sustained `upādāna / upādānakkhandha` problem cluster and the first part of the 1898 article. Exact manuscript continuity, argument identity, and whether Senart was named in the 1897 communication remain unproved.

Notebook 004 supplies a separate methodological control. Temporal sequence, logical classification, etymology, usage, provenance, function, resemblance, and genealogy repeatedly receive separate proof burdens.

Compact rule:

> **one relation is not allowed automatically to answer for another.**
