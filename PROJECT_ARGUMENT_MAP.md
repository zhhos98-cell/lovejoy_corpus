## 1. Core project problem

The project asks how Lovejoy's late-1890s work moved between textual criticism, comparative religion, philosophical reconstruction, and later published abstraction, with special attention to the evidential operations visible in notebooks 004/005 and the 1897–98 publication path.

The current working emphasis is source-critical and Lovejoy-local:

> **different relations require different warrants, and the scale of the research object can change between notebook work, public title, article, and later synthesis.**

The key task is to reconstruct those operations from direct evidence without converting analytical resemblance across contemporaries into a historical argument.
